    The field guide

    A little less mystery.
    A lot more clarity.

    Grimoire turns a project link into an explorable technical briefing. Here is how to get a useful reading without pretending an AI can magically inspect every repository.

    01

    Start with a link

    Bring a project

    Paste a GitHub repository or website URL on the New Link page. A clear, public project name gives the model a better starting point.

    02

    Add evidence

    Give it context

    README text, package files, architecture notes, or a short code excerpt can improve the explanation, especially for new or obscure projects.

    03

    Explore the result

    Switch perspectives

    Use Wizard-born for technical detail or Muggle London for a plain-language explanation. Architecture and flow diagrams update with the selected mode. Use Regenerate if a reading feels off, or Copy as Markdown / Download JSON to keep a copy.

    04

    Keep your work

    Return any time

    Your recent decodes are saved in this browser. Open the Library to revisit them without spending another API request.

    A useful limitation

    AI explanations are a starting point, not source-code verification.

    Grimoire sends the link and any context you provide to the AI provider you select. It does not crawl the live repository itself, so verify important implementation details against the actual source before relying on them.

    Decode a project ↗
    Grimoire asks your selected AI provider to read the link and reason it out — double-check anything load-bearing against the real source. Runs entirely in your browser; your API key never leaves it.
